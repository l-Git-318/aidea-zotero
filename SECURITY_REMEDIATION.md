# Security remediation — 2026-10-04

- Treat model output as untrusted: disable KaTeX trust, escape HTML, allow only credential-free HTTP(S) Markdown links, and render remote images as explicit links. Only inert PNG/JPEG/GIF/WebP data images can load automatically.
- Authenticate the loopback OAuth proxy with a random per-process bearer token. Validate Host, reject browser Origin and transfer encoding, bound JSON bodies, request time and concurrent connections. Upstream credentials remain in memory rather than in the proxy client configuration.
- Restrict translation directories/files to 0700/0600, delete sensitive task/config files on completion and error, and remove crash leftovers older than 24 hours on the next translation. Retain translation outputs. The bridge consumes and immediately removes task.json.
- Remove the embedded Gemini OAuth credential fallback. Obtain application credentials only from the locally installed Gemini CLI, including its newer bundle format, using bounded chunk reads without logging them.
- Use an independent cryptographically random OAuth state, require PKCE S256, validate callback state on both sides, and write single-use callback results with mode 0600. Invalid callbacks cannot terminate login; responses are inert plain text.
- Upgrade vulnerable build/test dependencies and Astro. Pin workflow actions to commit SHAs and restrict token permissions by job. Remove the committed Python bytecode cache.
- `http-cache-semantics` 4.2.0 has no published upstream fix for GHSA-ch52-4w7c-c8xp in the reviewed advisory snapshot. The licensed local copy in site/vendor checks no-store/no-cache/proxy-revalidate before max-stale; site tests verify these boundaries and preserve valid public cache hits. Replace this patch when a verified upstream fix becomes available.

Validation: 453 TypeScript unit tests passed (1 existing pending test), 110 Python bridge checks, 3 authenticated proxy boundary tests, plugin build and type checking, 5 cache regression tests, and the 12-page static site build. Chromium checks use the real KaTeX renderer and confirm active links are blocked and remote images do not auto-load. These checks do not replace installation testing in the native Zotero runtime or a live Google OAuth flow. Unix mode permissions do not replace a user's Windows account ACLs. Restart the plugin after updating so previously started processes cannot retain the old code.
